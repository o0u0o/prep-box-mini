# 2. 数据来源与合规展示规范

本项目展示的企业信息用于求职前背景参考。所有涉及企业风险、劳动争议、失信被执行、行政处罚、薪资点评等内容，均应遵循“公开可核验、客观中立、最小必要、可申诉更正”的原则。

## 一、优先采用的数据来源

优先收录以下公开、可核验来源：

1. 国家企业信用信息公示系统、信用中国等官方企业信用平台；
2. 中国执行信息公开网、人民法院公告、裁判文书等司法公开信息；
3. 人社、市场监管、税务、住建、应急管理等行政机关公告；
4. 主流媒体对官方公告或已公开事实的报道；
5. 用户主动提交且能够提供公开链接、案号、文书编号、处罚决定书编号、仲裁/判决材料等核验依据的线索。

## 二、不应收录或应谨慎展示的内容

以下内容不得直接公开展示，或应在复核前保持隐藏：

1. 无法核验的主观指控、辱骂性表达、情绪化评价；
2. “骗子公司”“传销组织”等未经司法或行政机关明确认定的定性表述；
3. 未公开案件材料、未生效裁判/仲裁内容、商业秘密；
4. 身份证号、手机号、住址、家庭情况、聊天记录原图等个人隐私或敏感个人信息；
5. 与求职风险无关、超出最小必要范围的信息。

## 三、字段展示要求

- `uscc`：统一社会信用代码。应来自官方公开工商信息、行政/司法公告或其他可核验来源；无法确认时留空，不猜测。
- `legal_rep_name`：法定代表人姓名。仅展示企业登记或官方公告中公开披露的姓名；无法确认时留空或显示“未公开”。
- `source`：记录来源说明。优先填写原始链接、公告标题、发布日期、案号/处罚决定书编号；无法提供链接时，应写明核验渠道和检索关键词。
- `remark`：仅作客观事实摘要。避免主观定性、攻击性措辞和超出来源范围的推断。
- `is_real`：仅表示“已有来源记录/待进一步复核”，不表示平台对事实作最终认定。

## 四、页面展示声明

页面应在企业详情、风险标签、薪资/点评附近展示近场提示：

> 本页信息基于公开来源或用户提交材料整理，仅供求职前背景参考，不代表平台对企业作出最终定性；企业状态、司法/行政记录请以官方最新公示为准。

薪资与点评内容如来自用户投稿，应额外提示：

> 用户提交内容不代表平台观点；涉及争议事实的，请结合公开裁判文书、行政公示或企业说明自行核验。

## 五、申诉、更正与下架

被提及企业、当事人或其他权利人可通过小程序“申诉 / 反馈”入口提交材料。收到后应按以下顺序处理：

1. 核验申诉主体或材料是否与条目相关；
2. 对比官方最新公示、原始来源与用户提交材料；
3. 对确有错误、来源失效、状态已解除、内容超范围或涉及侵权风险的条目，进行更正、隐藏或删除；
4. 保留必要处理记录，以便后续追溯。

## 六、维护建议

1. 高风险标签应尽量使用官方名称，如“失信被执行”“行政处罚”“重大劳动保障违法”；
2. 对涉嫌违法犯罪或严重损害商业信誉的高敏感定性标签，应仅在有明确官方或权威来源支持时使用；
3. 不要在生产环境将开发模拟薪资/点评数据自动展示到真实企业详情页；
4. 定期抽查来源链接是否有效、企业状态是否发生变化。
